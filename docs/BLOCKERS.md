# LepiLED DIY Maxi Switch — Pre-Order & Build Checklist (Rev 4.8)

All automated electrical, PCB/Gerber, SPICE, thermal, CAD (including ray-cast wall-breach & 14-insert B-Rep checks), and BOM verification gates pass with zero open blockers via `python3 verify_all.py --check`. For the complete history of resolved engineering findings, see [DESIGN_DECISIONS.md](DESIGN_DECISIONS.md), and for the change-propagation procedure, see [CHANGE_CHECKLIST.md](CHANGE_CHECKLIST.md).

## Routine Pre-Order Checks

| Item | What to Check Before Ordering |
|---|---|
| **1. JLCPCB Full-SMD ENIG PCBA (`driver_pcb`)** | Upload [driver_pcb_gerbers.zip](../pcb_design/gerbers/driver_pcb/driver_pcb_gerbers.zip), [driver_pcb_bom_pcba_hybrid.csv](../pcb_design/driver_pcb_bom_pcba_hybrid.csv), and [driver_pcb_cpl_hybrid.csv](../pcb_design/driver_pcb_cpl_hybrid.csv) (**ENIG** finish, Top-Side Economic PCBA, Qty `2`). JLCPCB assembles **all `48` SMDs** (`20` Basic + `7` Extended reels: `U1/U2`, `U3`, `F1`, `D11`, `L1/L2`, `R3/R4`, `R7`); select **"Remove order number"** for a clean Emperor-moth back silkscreen, verify polarized part orientation in JLCPCB's 3D viewer, and order only the **`4` THT connectors (`J1..J4`)** in [driver_pcb_diy_hand_solder.csv](../pcb_design/driver_pcb_diy_hand_solder.csv) alongside `SW1` + `SW1_BOOT` from Farnell UK / RS UK. *(Optional industrial upgrade for sub-zero or `> 30 °C` builds: swap `U4` from Basic `LM393DR2G` `C7955` to `LM2903DR2G` `C57474`.)* |
| **2. Plexiglass Shroud & PMMA-Safe Silicone** | Specifically order **Röhm `PLEXIGLAS® XT Clear 0A070` (`29070`)** (`Ø60 × 54 × 3.0 × 115 mm`, Amari Plastics UK / Acrylglas-Shop) — **never** UV-blocking cast `GS` or polycarbonate. Verify 365 nm transmission on arrival using the white-paper fluorescence bench check in [ASSEMBLY_GUIDE.md](ASSEMBLY_GUIDE.md). Never clean PMMA with IPA! Order **`OTTOSEAL® S 72 Clear`** (`MECH-SEAL-1`) and cure open-air for `48 h` before sealing. |
| **3. LED Stars (`D1..D8`) & Nylon Insulation** | Order `4× SST-10-UV 365 nm` + `1× XP-E2 Cool White` from Kaidomain, and `2× XP-E2 Royal Blue 455 nm` + `1× XP-E2 Green 528 nm` from LED-TECH.DE (`20 mm` stars with electrically neutral thermal pads). Install with `16× M3` DIN 125 nylon washers edge-clamping at `R = 11.7 mm`. |
| **4. 3D Printing & Chimney-Only Paint** | Print all 8 support-free parts on a workshop printer in **Black PETG or ASA** (avoid plain PLA; Signal-Orange PETG/ASA for `MECH-HANG-BUSHING`). Spray matte-black high-temp paint **only on the top `58.5 mm` protruding chimney** — keep the interior bare mill aluminum! |
