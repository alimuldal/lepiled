# LepiLED DIY Maxi Switch — Pre-Order & Build Checklist

For the revision history and design rationale, see [DESIGN_DECISIONS.md](DESIGN_DECISIONS.md); for the change-propagation procedure, see [CHANGE_CHECKLIST.md](CHANGE_CHECKLIST.md).
